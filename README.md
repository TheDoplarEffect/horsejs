# horsejs

Interactive 3D horse built with Three.js — fully procedural model (no external assets), PBR materials, soft shadows, and gait animation.

## Run it

Download **`horse.html`** and double-click it — it is a single self-contained file (Three.js is inlined) and runs offline in any modern browser. No server needed.

## Controls

- Drag / scroll / right-drag — orbit, zoom, pan
- Click the ground — the horse walks/trots there
- Click any body part — inspect it (hover highlights + tooltip)
- Buttons or keys `1–4` — Idle / Walk / Trot / Gallop, `Space` — gallop burst
- Head and ears follow your mouse cursor
